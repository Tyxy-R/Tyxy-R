## About Me

M.S. student in Automation at Shanghai Jiao Tong University, Class of 2029. I focus on building reliable LLM applications, multi-agent systems, long-term memory, and GraphRAG.

- Former LLM Application R&D Intern at Meituan Infrastructure R&D Platform
- Owned the 0-to-1 delivery of a multi-agent long-term memory and personalized context system
- Worked on heterogeneous agent integration, memory extraction, user profiling, retrieval, and context injection
- Built GraphRAG multi-agent workflows with Neo4j and LangGraph
